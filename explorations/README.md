# explorations/

Early studies and scratch scripts from the development of the method:
motivation experiments, detector-selection visualizations, gap-sensitivity
and lifetime collection, and a first version of the runtime estimator.
Read together, they trace how the ideas in the paper took shape, from the
first questions we asked to the design that `algorithms/` now implements.

Nothing outside this folder depends on it, and the results of the paper
are not produced from it; the maintained versions of these ideas live in
`algorithms/` and `experiments/`. It is kept for completeness only, as is,
and the scripts may reference paths or interfaces that no longer exist.
